# Sara TUI

Sara の要件・設計文書を端末で検索し、本文や関連文書をたどれる Rust 製の TUI。

## 起動する

`sara` 0.12.3 と Rust 1.88 以降を使う。本文の表示には `leaf` を `PATH` に用意する。編集には `$EDITOR` を使い、空か未設定の場合は `vim` を使う。 [leaf のインストール手順](https://github.com/RivoLink/leaf#installation)

このリポジトリのルートで起動し、`--project` に `sara.toml` があるディレクトリを指定する。隣に `sara-self-model` を置いている場合は次のコマンドで開ける。

```sh
cargo run --locked -- --project ../sara-self-model
```

Nix で Rust と Cargo を用意して実行する場合は、次のコマンドを使う。

```sh
nix --extra-experimental-features 'nix-command flakes' shell nixpkgs#cargo nixpkgs#rustc \
  --command cargo run --locked -- --project ../sara-self-model
```

`--project` を省略すると、起動時の作業ディレクトリを開く。

## 操作する

画面には濃紺の背景と薄紫のアクセントを使う。サイドバーは文書をタイプごとにまとめ、`sara schema` の定義順に表示する。各グループの右端には表示対象の文書数が出る。文書を選ぶと `leaf --inline` が本文ペインの幅に合わせて描画する。端末の幅が狭い場合はツリーの下に本文が表示される。

| キー | 操作 |
| --- | --- |
| `?` | 画面中央にキーバインド一覧を開く。`?` または `Esc` で閉じる |
| `/`、`Enter` | `/` で画面の最下行に検索欄を開き、`Enter` で名前、ID、本文などを検索する。空のまま確定すると全件に戻る |
| `1` / `2` / `3` | 文書ツリー、本文、関連文書にそれぞれ移る。`Tab` / `Shift+Tab` でも切り替えられる |
| `↑` / `↓` または `k` / `j` | 選択を移動する。文書ツリーでは選択した文書をその場で表示し、本文ではスクロールする |
| `←` / `→` または `h` / `l` | 文書タイプのグループを閉じる・開く。開いているグループから文書へ、文書からグループへ移動できる |
| `Enter` / `o` / `Space` | サイドバーでグループを開閉する。文書を選択している場合は本文へ移る |
| `→` / `l` | サイドバーで文書を選択しているときに本文へ移る |
| `←` / `h` | 本文からサイドバーへ移る |
| `Enter` | 関連文書の一覧で選んだリンクをたどる |
| `o` | 本文にフォーカスがあるとき、元の Markdown を `$EDITOR` で開く。エディターを終了すると保存内容を読み直す |
| `b` / `Esc` | `b` でリンクをたどる前の文書に戻る。`Esc` で検索入力を取り消す。検索確定後に `Esc` を押すと絞り込みを解除して文書ツリーに戻る |
| `[` / `]` または `PageUp` / `PageDown` | 文書ツリーの選択を画面単位で移す |
| `v` / `r` | `v` でモデルを検証し、`r` で検索結果を読み直す |
| `q` | 終了する |
